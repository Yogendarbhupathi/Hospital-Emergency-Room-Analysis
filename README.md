📌 Overview
This project showcases a complete hospital emergency room data analysis using Microsoft Excel.
It provides key healthcare insights through an interactive and visually appealing dashboard, helping hospitals optimize emergency operations and improve patient care outcomes.

🎯 Project Objectives
Analyze emergency room performance metrics.
Monitor patient admission trends, gender distribution, and department referrals.
Measure average wait time and patient satisfaction scores.
Enable data-driven decision-making for hospital management.

⚙️ Tools & Techniques Used
Microsoft Excel
Power Query – Data cleaning and transformation.
Power Pivot – Data modeling and relationships.
DAX Formulas – Calculated measures and KPIs.
PivotTables & Charts – Data summarization and visualization.
Interactive Dashboard – Slicers and dynamic visuals for exploration.

💡 Key Learnings
Developed expertise in Excel-based ETL workflows using Power Query and Power Pivot.
Created interactive dashboards that highlight performance and efficiency metrics.
Enhanced ability to interpret healthcare data and derive actionable insights.
